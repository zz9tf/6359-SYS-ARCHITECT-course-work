\textbf{Lessons for system design.} (1)~Weight-only formats save bandwidth but not compute; in the
compute-bound regime only formats that tensor cores run natively (FP8 here, FP4 on the newest GPUs)
help. (2)~The software stack matters as much as the format. (3)~With 4-bit weights, the KV cache
dominates memory at long contexts, so KV-cache quantization~\cite{liu2024kivi,hooper2024kvquant} is
the natural next step.

\section{Conclusion}
\label{sec:conclusion}
On one consumer GPU, the bit-width alone predicts neither the memory a quantization format saves,
nor its speed, nor its quality cost. Memory savings are real but smaller than advertised. Speed
depends on the implementation and the regime: fused weight-only kernels win at small batches, FP8 at
every batch size. Quality costs grow as bits and model size shrink, yet a larger 4-bit model beats a smaller
16-bit one. Smaller is not always faster, but with the right kernel in the right regime, it is both.
