\subsection{Threats to validity}
\label{sec:limits}
\emph{One GPU and one model family.} All results come from a single RTX 5090 and dense Qwen2.5
models. The mechanism we identify is architectural (bytes per weight against arithmetic
intensity), so the qualitative picture should carry over to other GPUs, but the crossover
batch sizes scale with each GPU's FLOP-to-bandwidth ratio and must be re-measured.
\emph{Library versions.} Kernel coverage moves fast: newer bitsandbytes releases may close part of the
gap we measure, and vLLM picks kernels per GPU architecture. We pin every version and release the
harness so the study can be re-run.
\emph{Uncontrolled clocks.} The GPU also drives the workstation's display and we could not lock clocks
without administrator rights. Repetitions agree closely (\cref{sec:method}), and we report means.
\emph{Synthetic prompts.} Random token ids exercise exactly the same kernels as natural text in a
dense model, but they are out of distribution, which is why quality is measured separately on
WikiText-2 and GSM8K and speed on real ShareGPT traffic.
\emph{Greedy decoding.} Quality numbers use greedy decoding, the single most common evaluation
setting; sampling would add variance but would not change the cost of a step.
